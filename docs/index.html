🦊 A self-hosted alternative to the late Firefox Send

Send files securely.
Without giving up control.

GoFileBeam is an open-source, single-binary file sharing server with end-to-end encryption, automatic expiration, and a storage quota you set — so you can run your own private "Send" on your own infrastructure.

Features

Everything Firefox Send did well, and more

Built for privacy-conscious teams and individuals who want full ownership of their file sharing infrastructure.

End-to-end encryption

Files are encrypted with AES-256-GCM before they ever touch disk. Add a password and only someone with that password can decrypt the download.

Automatic expiration

Set links to expire after a number of downloads, a time period, or both — exactly like Firefox Send's "1 download / 1 day" style policies.

Storage quota control

Cap total disk usage at the limit you choose. GoFileBeam reports real-time usage and refuses uploads once the quota is reached.

Single binary

No database, no external dependencies, no runtime to install. Build once, copy the binary anywhere, and run it.

Drag-and-drop web UI

A clean, built-in web interface for uploading, setting a password, picking an expiration policy, and sharing the link — no extension required.

REST API

Upload and download programmatically with a simple HTTP API — integrate GoFileBeam into scripts, CI pipelines, or other apps.

Quick Start

Up and running in under 5 minutes

Build, run, and start sharing files from your own server.

1

Build the binary

Clone the repository and build with Go 1.19 or later.

2

Run the server

Starts on http://localhost:8080 by default, with rate limiting, brute-force protection, and sandboxing enabled out of the box.

3

Open the web UI

Drag and drop a file, optionally set a password and expiration policy, and share the generated link.

4

(Optional) Configure for production

Set storage path, quota, port, and HTTPS via environment variables, or run it as a systemd service.

Build & run

# Build the binary
go build -o gofilebeam ./cmd/gofilebeam

# Run it
./gofilebeam

# Service will be live at http://localhost:8080

Upload a file via the API

# Upload with a password and 7-day expiration
curl -F "file=@report.pdf" \
  -F "expiration_option=10 Downloads or 7 Days" \
  -F "password=correct-horse-battery-staple" \
  http://localhost:8080/api/upload

# Download it back
curl "http://localhost:8080/api/download/<file_id>?password=correct-horse-battery-staple" \
  -o report.pdf
